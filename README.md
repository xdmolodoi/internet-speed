# Internet Speed Tester

Скрипт на Python для замера скорости интернета: делает 10 последовательных
запросов к тяжёлой картинке, считает среднее время запроса, объём
скачанных данных и скорость в МБ/с.

## Требования
- Python 3.10+
- Библиотека `requests`

## Установка
```bash
pip install requests
```

## Запуск
```bash
python speed_test.py
```

## Как это работает
Скрипт скачивает картинку (~14 МБ) 10 раз подряд, замеряет время каждого
запроса, суммирует объём данных и в конце печатает в консоль среднее время
запроса, общий объём и скорость в МБ/с.
